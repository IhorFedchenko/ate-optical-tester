# ATE Optical Tester

Автоматизований випробувальний комплекс (ATE) для діагностики та валідації активних оптичних каналів зв'язку (UART / CRSF, PAL Video).

Принцип роботи: прийом та передача пакетів CRSF по uart в режимі loopback та аналіз прийнятих контрольних пакетів CRC.

Hardware; ESP32, CRSF TX/RX
